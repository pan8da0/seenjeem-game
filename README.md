# اشتباك (Eshtebak)

لعبة أسئلة وأجوبة عربية ممتعة لفريقين، مبنية بالكامل بـ **HTML و CSS و JavaScript فقط** — بدون خادم (server)، وبدون قاعدة بيانات، وبدون تسجيل دخول. كل شيء يعمل مباشرة من المتصفح، ويمكن نشرها **مجانًا** على GitHub Pages أو Vercel أو Netlify.

> **Made for Jana** 💜

هذا الدليل مكتوب لشخص **بدون خبرة برمجية سابقة**. اتبع الخطوات بالترتيب.

## 1. تشغيل اللعبة على جهازك

اللعبة عبارة عن ملفات HTML/CSS/JS عادية، لذلك تشغيلها محليًا بسيط جدًا. اختر إحدى الطريقتين:

### الطريقة الأولى: افتح الملف مباشرة (أسهل طريقة)

افتح ملف `index.html` بالنقر المزدوج عليه، سيفتح في متصفحك مباشرة. **تعمل اللعبة بالكامل بهذه الطريقة** (بدون سيرفر) لأن جميع البيانات محمّلة عبر ملفات JavaScript عادية وليس عبر طلبات شبكة.

### الطريقة الثانية: خادم محلي بسيط (اختياري، لتجربة أقرب للموقع الحقيقي)

إذا كان لديك Python مثبتًا على جهازك:

```bash
cd seenjeem-game
python3 -m http.server 8000
```

ثم افتح المتصفح على: `http://localhost:8000`

إذا كان لديك Node.js:

```bash
npx serve .
```

## 2. فتح الموقع

بعد تشغيل اللعبة (محليًا أو من الرابط المنشور)، الصفحات المتوفرة هي:

| الصفحة | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية (تبدأ منها) |
| `game.html` | صفحة اللعب (تُفتح تلقائيًا عند الضغط على "ابدأ لعبة جديدة") |
| `admin.html` | لوحة إدارة الأسئلة والفئات |

## 3. كيف تضيف سؤالًا جديدًا

عندك طريقتان: عبر **لوحة الإدارة** (سهلة، بدون كتابة كود) أو عبر **تعديل الملفات مباشرة** (للتحكم الكامل والنشر الدائم).

### الطريقة أ: عبر لوحة الإدارة (`admin.html`) — لتجربة سريعة

1. افتح `admin.html`.
2. اذهب لتبويب **"الأسئلة"**.
3. اختر الفئة من القائمة المنسدلة.
4. اضغط **"إضافة سؤال"**.
5. اكتب نص السؤال، نص الإجابة، اختر الصعوبة (سهل/متوسط/صعب)، واختياريًا مسار صورة.
6. اضغط **"معاينة"** للتأكد من الشكل، ثم **"حفظ"**.

⚠️ **مهم جدًا:** هذا الحفظ يتم في متصفحك فقط (LocalStorage). إذا أردت أن يرى أصدقاؤك هذا السؤال الجديد على الموقع المنشور، يجب أن **تُصدّر (Export)** البيانات وتستبدل بها ملفات `/data` ثم تنشر الموقع من جديد. راجع [القسم 12](#12-استيراد-وتصدير-الأسئلة-import--export).

### الطريقة ب: تعديل الملفات مباشرة (تُنشر بشكل دائم عبر GitHub)

كل فئة لها ملف خاص بها داخل `data/questions/`. مثال: أسئلة كرة القدم موجودة في `data/questions/football.js`.

افتح الملف وأضف سؤالًا جديدًا بنفس الشكل (لاحظ الفاصلة `,` في نهاية كل سؤال ما عدا الأخير):

```js
{ id: 'football_041', question: 'سؤالك هنا؟', answer: 'الإجابة هنا', difficulty: 'easy', image: null },
```

- **id**: يجب أن يكون فريدًا (غير مكرر) داخل نفس الملف. استمر بنفس الترقيم.
- **difficulty**: واحدة من `easy` (100 نقطة) أو `medium` (200 نقطة) أو `hard` (300 نقطة).
- **image**: اتركه `null` إن لم يكن هناك صورة.

احفظ الملف وارفعه (commit + push) إلى GitHub.

## 4. كيف تعدّل سؤالًا موجودًا

- **عبر لوحة الإدارة**: تبويب "الأسئلة" ← ابحث عن السؤال ← اضغط "تعديل".
- **عبر الملفات**: افتح `data/questions/<اسم-الفئة>.js`، عدّل نص `question` أو `answer` أو `difficulty` أو `image`، واحفظ.

## 5. كيف تضيف فئة جديدة

### عبر لوحة الإدارة

تبويب "الفئات" ← "إضافة فئة" ← املأ الحقول (المعرّف، الاسم بالعربية والإنجليزية، الوصف، اللون، الأيقونة) ← "حفظ".

### عبر الملفات (للنشر الدائم)

**الخطوة 1:** أضف الفئة في `data/categories.js`:

```js
{
  id: 'my_new_category',
  nameAr: 'اسم الفئة',
  nameEn: 'Category Name',
  color: '#3366FF',
  icon: 'star',
  descriptionAr: 'وصف قصير بالعربية',
  descriptionEn: 'short description in English'
}
```

**الخطوة 2:** أنشئ ملف أسئلة جديد `data/questions/my_new_category.js`:

```js
window.QUIZ_QUESTIONS = window.QUIZ_QUESTIONS || {};
window.QUIZ_QUESTIONS.my_new_category = [
  { id: 'my_new_category_001', question: '...', answer: '...', difficulty: 'easy', image: null },
  // أضف 40 إلى 60 سؤالًا للحصول على تجربة لعب جيدة بدون تكرار سريع
];
```

**الخطوة 3:** أضف سطر `<script>` للملف الجديد في **كل من** `game.html` و`admin.html` (بجانب باقي أسطر `data/questions/...`):

```html
<script src="data/questions/my_new_category.js"></script>
```

ضع السطر **قبل** سطر `<script src="js/core/catalog.js">` وبعد باقي ملفات الأسئلة.

لا حاجة لتعديل أي كود آخر — النظام يقرأ الفئات والأسئلة تلقائيًا مهما زاد عددها.

## 6. كيف تغيّر لون فئة

كل فئة لها خاصية `color` (كود لون HEX) داخل `data/categories.js`. غيّره لأي لون تريده، مثال:

```js
color: '#E23B4E',
```

يظهر هذا اللون تلقائيًا في: بطاقة الفئة، لوحة اللعب، شارة السؤال، ولوحة الإدارة — من نفس المكان الواحد.

**نصيحة:** اختر ألوانًا واضحة (ليست فاتحة جدًا) حتى يبقى النص الأبيض فوقها مقروءًا بوضوح.

---

## 7. كيف تضيف صورة لسؤال

1. ضع ملف الصورة داخل مجلد `images/questions/` (أنشئ المجلد إذا لم يكن موجودًا).
2. في تعريف السؤال، اكتب مسار الصورة النسبي:

```js
{ id: 'football_012', question: 'من هو هذا اللاعب؟', answer: '...', difficulty: 'medium', image: 'images/questions/player1.jpg' },
```

إذا كانت الصورة غير موجودة أو المسار خاطئ، تختفي الصورة تلقائيًا ويبقى السؤال يعمل بشكل طبيعي بدون أي كسر في التصميم.

---

## 8. كيف تغيّر اسم اللعبة

اسم اللعبة موجود في ملف الترجمة `js/core/translations.js`، ابحث عن:

```js
appName: 'اشتباك',
```

(وفي قسم `en` بالأسفل: `appName: 'Eshtebak',`)

غيّرهما للاسم الذي تريده. سيتحدث الاسم تلقائيًا في كل الصفحات (الرئيسية، اللعب، عنوان التبويب في المتصفح).

---

## 9. كيف تغيّر الشعار (اللوغو)

الشعار الحالي هو رسمة SVG بسيطة مكتوبة مباشرة داخل `index.html` (داخل `<div class="brand-mark">`). لتغييره:

- **لتعديل الشكل الحالي**: عدّل إحداثيات `<path>` أو الألوان (`fill="#..."`) مباشرة داخل الكود.
- **لاستخدام صورة شعار خاصة بك**: استبدل محتوى `<div class="brand-mark">` بـ:

```html
<div class="brand-mark">
  <img src="images/my-logo.png" alt="Logo" style="width:100%;height:100%;object-fit:contain;border-radius:inherit;">
</div>
```

نفس الأمر لأيقونة المتصفح (favicon): استبدل `images/favicon.svg`.

هذا النص ثابت بالإنجليزية بحسب الطلب. يوجد مباشرة داخل `index.html`:

```html
<p class="made-for-jana">Made for Jana</p>
```

## 11. كيف تعمل الترجمة عربي/إنجليزي

كل نصوص الواجهة موجودة في مكان واحد: `js/core/translations.js`. الملف يحتوي على كائنين: `ar` و`en`، كل مفتاح (key) له نص بكل لغة.

لإضافة أو تعديل نص:

```js
ar: {
  myNewKey: 'النص بالعربية',
  ...
},
en: {
  myNewKey: 'The English text',
  ...
}
```

ثم استخدمه في أي ملف HTML بإضافة `data-i18n="myNewKey"` على العنصر، أو في JavaScript عبر `I18n.t('myNewKey')`.

اللغة الافتراضية هي **العربية** مع اتجاه **RTL** تلقائي. زر التبديل (العربية | English) موجود في كل صفحة، ويُحفظ اختيار المستخدم في LocalStorage.

**سؤال ولعبة الأسئلة نفسها** (نصوص الأسئلة والإجابات) لا تُترجم تلقائيًا — هي بالعربية بشكل أساسي كما طُلب. يمكنك إضافة أسئلة بالإنجليزية أيضًا إذا أردت، لكن النظام لا يبدّل محتوى الأسئلة حسب اللغة المختارة.

## 12. استيراد وتصدير الأسئلة (Import / Export)

بما أن GitHub Pages (وأي استضافة ثابتة أخرى) **لا يمكنها تعديل ملفات المستودع مباشرة من المتصفح**، فإن لوحة الإدارة تحفظ كل التعديلات في متصفحك فقط (LocalStorage). لنشر هذه التعديلات للجميع:

### خطوات النشر الفعلي للتعديلات

1. افتح `admin.html` وعدّل/أضف ما تريد (فئات، أسئلة، ألوان...).
2. اذهب لتبويب **"استيراد / تصدير"**.
3. اضغط **"تصدير JSON"** — سيُنزَّل ملف باسم `eshtebak-questions.json` يحتوي على **كل** الفئات والأسئلة (الأصلية + تعديلاتك) بصيغة موحّدة.
4. افتح الملف المُصدَّر، وباستخدامه كمرجع، حدّث ملفات `data/categories.js` و`data/questions/*.js` يدويًا بنفس القيم (أو استخدم الملف مباشرة كأساس لإعادة كتابة تلك الملفات بصيغة JavaScript).
5. ارفع (commit + push) التعديلات إلى GitHub — سيُحدَّث الموقع المنشور تلقائيًا خلال دقيقة أو دقيقتين.

### استيراد ملف JSON

من نفس التبويب، اضغط **"استيراد JSON"** واختر ملفًا بنفس الصيغة (مثلًا نسخة معدّلة من ملف مُصدَّر سابقًا، أو ملف أرسله لك صديق). **تنبيه:** الاستيراد يستبدل كل البيانات المحلية الحالية بالكامل.

### استرجاع البيانات الأصلية

زر **"استرجاع البيانات الأصلية"** في نفس التبويب يحذف كل تعديلاتك المحلية ويُعيد قاعدة البيانات إلى ما هو مرفق أصلًا مع الموقع.

## 13. كيف يعمل التخزين المحلي (LocalStorage)

اللعبة لا تستخدم أي خادم أو قاعدة بيانات خارجية — كل شيء يُحفظ داخل متصفح اللاعب نفسه عبر `LocalStorage`، وهذا يشمل:

| البيانات | المفتاح (Key) |
|---|---|
| اللعبة الحالية (لإكمالها بعد تحديث الصفحة) | `eshtebak:currentGame` |
| الإعدادات (المؤقّت، عدد الفئات، الصوت، اللغة) | `eshtebak:settings` |
| الأسئلة التي ظهرت مؤخرًا لكل فئة (لتقليل التكرار) | `eshtebak:recentQuestions` |
| اللغة المختارة | `eshtebak:language` |
| تعديلات لوحة الإدارة (فئات/أسئلة مضافة أو معدّلة أو محذوفة) | `eshtebak:customCategories`, `eshtebak:customQuestions`, `eshtebak:deletedCategoryIds`, `eshtebak:deletedQuestionIds` |

**ملاحظات مهمة:**
- هذه البيانات **محلية بالكامل** لكل جهاز/متصفح — لا تُشارك بين اللاعبين تلقائيًا.
- مسح "بيانات التصفح" (Clear browsing data) من المتصفح يمسح هذه البيانات أيضًا.
- التصفح الخاص (Incognito/Private) لا يحفظ البيانات بعد إغلاق النافذة.

## 14. النشر المجاني على GitHub Pages

المشروع **جاهز بالكامل** للنشر على GitHub Pages فورًا — كل الروابط نسبية (relative)، لا يوجد أي اعتماد على خادم، ولا يحتاج أي خطوة بناء (build step).

### الخطوات (تُنفَّذ مرة واحدة فقط)

1. تأكد أن كل الملفات مرفوعة إلى مستودع GitHub الخاص بك (commit + push).
2. في صفحة المستودع على GitHub، اذهب إلى: **Settings** (الإعدادات) ← **Pages** (من القائمة الجانبية).
3. تحت **"Build and deployment"** ← **"Source"**، اختر: **Deploy from a branch**.
4. تحت **"Branch"**، اختر الفرع الذي يحتوي على الملفات (مثلًا `main`) والمجلد **`/ (root)`**.
5. اضغط **Save**.
6. انتظر دقيقة أو دقيقتين، ثم ستظهر لك GitHub رابطًا بالشكل:

```
https://<اسم-المستخدم>.github.io/<اسم-المستودع>/
```

مثال لهذا المشروع: **`https://pan8da0.github.io/seenjeem-game/`**

بعد ذلك، أي `git push` جديد إلى نفس الفرع يُحدّث الموقع المنشور تلقائيًا خلال دقيقة أو دقيقتين — بدون أي خطوة إضافية.

### لماذا لا يوجد GitHub Actions workflow هنا؟

لأن الموقع **ثابت بالكامل (static)** ولا يحتاج أي خطوة بناء (compilation/bundling) — ملف `index.html` يعمل كما هو. طريقة "Deploy from a branch" أبسط وأكثر موثوقية لهذه الحالة، ولا تحتاج صلاحيات GitHub Actions إضافية.

## 15. النشر على Vercel (اختياري)

1. أنشئ حسابًا مجانيًا على [vercel.com](https://vercel.com) وسجّل الدخول عبر GitHub.
2. اضغط **Add New → Project**، واختر مستودع GitHub الخاص بهذا المشروع.
3. لا حاجة لأي إعدادات بناء خاصة (Framework Preset: **Other**، Build Command: فارغ، Output Directory: `.`).
4. اضغط **Deploy**. سيعطيك Vercel رابطًا مجانيًا خلال ثوانٍ.

ملف `vercel.json` المرفق في المشروع يضمن تصرفًا صحيحًا للروابط.

---

## 16. النشر على Netlify (اختياري)

1. أنشئ حسابًا مجانيًا على [netlify.com](https://netlify.com).
2. اضغط **Add new site → Import an existing project**، واختر المستودع.
3. اترك **Build command** فارغًا، و**Publish directory** كـ `.` (المجلد الجذر) — ملف `netlify.toml` المرفق يضبط هذا تلقائيًا.
4. اضغط **Deploy site**.

## 17. أهم الملفات التي ستحتاج لتعديلها

| أريد أن... | الملف الذي أعدّله |
|---|---|
| أضيف/أعدّل سؤالًا | `data/questions/<الفئة>.js` |
| أضيف فئة جديدة | `data/categories.js` + ملف جديد في `data/questions/` |
| أغيّر لون فئة أو أيقونتها | `data/categories.js` |
| أغيّر اسم اللعبة أو أي نص بالواجهة | `js/core/translations.js` |
| أغيّر الشعار | `index.html` (قسم `brand-mark`) و`images/favicon.svg` |
| أغيّر "Made for Jana" | `index.html` |
| أغيّر الألوان العامة للموقع (الخلفية، الأزرار...) | `css/base.css` (أعلى الملف، قسم `:root`) |
| أغيّر منطق اللعبة (النقاط، عدد الأسئلة، المؤقّت) | `js/core/gameEngine.js` |
| أضيف ميزة للوحة الإدارة | `js/pages/admin.js` |

## الأسئلة الشائعة

**هل يحتاج اللاعبون لإنشاء حساب؟**
لا. لا يوجد تسجيل دخول ولا حسابات إطلاقًا.

**هل هناك أي تكلفة؟**
لا. الاستضافة على GitHub Pages/Vercel/Netlify مجانية بالكامل لهذا النوع من المواقع.

**هل تعمل اللعبة بدون إنترنت بعد فتحها أول مرة؟**
تعمل معظم الوظائف محليًا، لكن الخطوط (Google Fonts) تحتاج إنترنت لأول تحميل. اللعبة (المنطق، الأسئلة، الحفظ) لا تحتاج أي اتصال بالإنترنت بعد تحميل الصفحة.

**كم عدد الفئات/الأسئلة التي يمكن إضافتها؟**
لا يوجد حد أقصى. النظام مصمم للتعامل مع مئات الفئات وآلاف الأسئلة دون تعديل منطق اللعبة.
